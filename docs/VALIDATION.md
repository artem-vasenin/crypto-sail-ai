# Crypto Sail AI v0.1.1-research — подтверждённые проверки

**Дата исправления:** 16 ноября 2026 г.  
**Исходная база:** пользовательский `arch.zip`.  
**Среда выполнения в этой проверке:** Linux amd64, Go 1.23.2 (минимум `go.mod`), libsqlite3 через CGO. На пользовательском Ubuntu до исправления успешны тесты и реальные вызовы Bybit/Qwen при Go 1.27.1–1.27.4. Версии и окружения не следует путать.

## Проверено на исходниках исправленного проекта здесь

- `GOTOOLCHAIN=local CGO_ENABLED=1 go test -count=1 ./...` — **11/11 пакетов OK**.
- `GOTOOLCHAIN=local CGO_ENABLED=1 go test -race -count=1 ./...` — **11/11 пакетов OK**, обнаруженных гонок в выполненных тестах нет.
- `GOTOOLCHAIN=local CGO_ENABLED=1 go vet ./...` — **OK**.
- `GOTOOLCHAIN=local CGO_ENABLED=1 go build -o bin/sail ./cmd/sail` — **OK**.
- `./bin/sail doctor -db <временная-база>` — `paper_only:true`, `sqlite_integrity:ok`.
- `./bin/sail paper -db <временная-база> -file testdata/paper-example.json` — **OK**, только синтетика.
- Адресные mock HTTP-регрессии: пять элементов с пустыми `reason_codes` отклоняются со ссылкой на поле/символ, содержимое ответа сохраняется для аудита, ошибочный пакет не создаёт решений/позиций.

## Что уже подтвердил пользователь на своей исходной версии до исправления

- `make check` и `bash scripts/verify_offline.sh` на Ubuntu с Go 1.27.x прошли.
- Публичные 100 часовых BTCUSDT свечей получены через Bybit REST.
- Surface обработал 821 инструмент и сохранил решения (597 CANDIDATE, 224 WATCH в последнем запуске).
- Реальная Qwen3-8B приняла 6 синтетических benchmark-сценариев (6/6 валидных JSON, все WAIT); это не доказательство аналитического качества.
- Реальная Qwen затем вернула 5 `REQUEST_DEEP_ANALYSIS` с `reason_codes: []`; прежний triage справедливо отказал с недостаточно информативной ошибкой. Это событие воспроизведено тестами и адресно исправлено.

## Чего ещё не проверяли

- Запуск **именно исправленной версии** на пользовательской Ubuntu с реальным Qwen llama.cpp; возможно потребуется уточнение совместимости JSON Schema `minItems` с серверной версией.
- Действительную полезность/точность аргументации и решений модели, в том числе READY/WAIT/REJECT на разнообразных рыночных ситуациях.
- Длительный непрерывный Observer, статистику торговли, реальное исполнение (в проекте нет реальных ордеров).

Для повторного теста на Ubuntu и безопасного обновления: `docs/UPGRADE_AND_GIT_RU.md`.
