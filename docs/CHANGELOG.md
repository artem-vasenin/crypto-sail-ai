# Журнал изменений

## v0.1.1-triage-fix — 16.11.2026

Исправлена работа с ответом реальной локальной Qwen3-8B: модель вернула пять `REQUEST_DEEP_ANALYSIS` с `reason_codes: []`, а валидатор отклонил весь пакет (`invalid triage content`). В JSON Schema для triage теперь `minItems: 1`; промпт требует фактологического объяснения, валидатор Go сообщает символ/поле и отклоняет пустые/пробельные коды и объяснения. Некорректный JSON сохраняется в метаданных ответа для аудита SQLite, не создавая торговых решений. Регрессионные тесты проверяют исходный сбой и отсутствие CLI-решений при ошибке. Исправление выполнено на исходниках из присланного пользователем `arch.zip`, без наложения старого патча.

Добавлено руководство по безопасной замене исходников и первоначальной инициализации Git. Runtime SQLite, WAL, бинарный файл не включаются в ZIP. Реальную Qwen после обновления необходимо проверить отдельно.

## v0.1.0-research — 15.11.2026

Первый независимый репозиторий. Новая структура на Go 1.23.2; Bybit public REST, Surface, набор Deep-признаков, direct Qwen Chat Completions, SQLite WAL/backup, WAIT DTO, автономная offline-проверка SL/TP/BE/trailing и PostOnly simulator. Первые тесты `httptest`, unit, storage recovery и race detector. Пользовательская документация на русском и `AGENTS.md`.

**Отдельно:** на дату выпуска реальные вызовы Bybit и Qwen на Ubuntu пользователя в рамках этого релиза ещё не проверялись; проект не предназначен для выставления реальных ордеров. Никакой старый v0.2.x код исполнения в исходники не копировался.
